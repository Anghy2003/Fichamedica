CONSULTORIOS ERP — FICHA TÉCNICA

Archivos:
- index.html
- styles.css
- script.js

Uso:
1. Mantenga los tres archivos en la misma carpeta.
2. Abra index.html en Chrome, Edge, Firefox o Safari.
3. No requiere servidor web ni instalación.
4. El botón “Imprimir / guardar PDF” usa la función de impresión del navegador
   (el documento tiene hoja de estilos de impresión: oculta menú, buscador y
   pestañas, y expande acordeones y paneles para que todo salga en el PDF).

Diseño:
- Sistema visual claro, con tipografías Inter / Inter Tight / JetBrains Mono
  cargadas desde Google Fonts. Si el equipo no tiene internet, el documento
  usa automáticamente las tipografías del sistema y se ve igual de correcto.
- Interfaz adaptable a escritorio, tablet y móvil.

Respaldo del diseño anterior:
- index.html.bak, styles.css.bak y script.js.bak conservan la versión previa.
  Puede eliminarlos cuando el nuevo diseño esté aprobado.

La ficha fue elaborada a partir del análisis del proyecto consultorios.zip y de la ampliación funcional solicitada para Hospitalización, Talento Humano/Nómina, Contabilidad integral/SRI, Emergencias, Enfermería, Quirófano, activos/mantenimiento y BI.
