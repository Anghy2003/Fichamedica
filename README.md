# Ficha Técnica — Consultorios ERP

Ficha técnica integral del ERP clínico **Consultorios ERP**: gestión clínica,
hospitalaria, administrativa, financiera y tributaria (Ecuador / SRI).

Sitio estático, sin dependencias ni build: `index.html`, `styles.css`, `script.js`.

## Contenido

Resumen ejecutivo · Arquitectura · 18 módulos del sistema · Hospitalización ·
Talento humano y nómina · Contabilidad integral y SRI · Reportes financieros y
fiscales · Tecnologías · Infraestructura recomendada · Seguridad y continuidad.

## Uso local

Abra `index.html` en cualquier navegador moderno. No requiere servidor.

## Despliegue

Desplegable en Vercel como sitio estático (sin framework ni comando de build).

## Características

- Diseño responsive (escritorio, tablet y móvil).
- Buscador y filtros por categoría sobre los módulos.
- Hoja de estilos de impresión: el botón «Imprimir / guardar PDF» expande
  acordeones y paneles para exportar el documento completo.
